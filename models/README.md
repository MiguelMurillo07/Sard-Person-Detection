# Pesos de modelos

Los checkpoints entrenados no se incluyen directamente en el repositorio porque pueden ser pesados.

Archivos principales generados durante el proyecto:

- YOLOv8n: `best.pt`, `last.pt`
- Faster R-CNN: `best.pth`, `last.pth`

Si se desean publicar, usar una de estas alternativas:

1. GitHub Releases.
2. Git LFS.
3. Google Drive / almacenamiento institucional con enlace desde el README.

Los patrones `*.pt` y `*.pth` están excluidos mediante `.gitignore`.
